Wszystkie ustalone warunki kandydata są spełnione:

- komplet ocen, jeden resolved model, brak błędów API i ucięć;
- V3 no_tool 18/18 osobno w raw i application;

- application poprawił się 42 → 53;
- brak przypadku z kontrolą 3/3 i kandydatem 0/3 w którymkolwiek trybie.

**Wynik procedury: kandydat V3.** Reguła zabraniała nowej regresji stałej
3/3 → 0/3; nie zabraniała pojedynczego błędu 3/3 → 2/3. Nie zmieniono jej
po ujawnieniu `intent_032`, ale regresji nie ukryto w średniej.
Wybór kandydata nie jest decyzją o wdrożeniu. Aktywny V0 nie został podmieniony.
Następny krok to T014.4: przegląd pozostałych błędów i jawna decyzja.

V3 application ma 88,33% poprawnych ocen i 83,33% obsługiwanych próśb.
Oba wyniki są poniżej liczbowych progów 90% ACC, a zbiór jest celowany
i ujawniony. Ta kampania nie zalicza ACC-09–ACC-11 ani całego MVP.
Nie porównywano równocześnie V2 z V3: poprawa względem V0 nie izoluje wpływu
samego nowego akapitu. Historyczny wynik V2 nie jest kontrolą tej kampanii.
